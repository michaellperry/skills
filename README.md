# Skills

Skills I install into repositories I work in.

## Install

```bash
npx openskills install michaellperry/skills
```

This installs into `.claude/skills/`. Commit what you install, and refresh from here rather than editing a copy in place.

## Skills

### degrees-of-freedom

My constitution for judging whether a system's representation is faithful to its problem: its degrees of freedom should equal the dimensionality of the problem, no more and no fewer. A repository adopts it by naming it as authority, and its issues then cite articles by number.
